🎓 EXAMPLE: COMPARE 3 STRATEGIES
═══════════════════════════════════════════════════════════════════════════════

  from backtester_standalone import *

  # Create assets
  assets = create_sample_assets()
  backtester = Backtester(assets)

  # Test 3 strategies
  results = [
      backtester.run(Strategies.buy_and_hold("TECH"), 100000, "Tech Only"),
      backtester.run(Strategies.buy_and_hold("BOND"), 100000, "Bonds Only"),
      backtester.run(
          Strategies.balanced_portfolio({"TECH": 0.5, "BOND": 0.5}),
          100000,
          "50/50 Mix"
      ),
  ]

  # Compare results
  Comparator(results).summary()

  # Output: Beautiful comparison table showing returns, risk, etc.

🎯 FEATURES AT A GLANCE
═══════════════════════════════════════════════════════════════════════════════

  Asset Types:
    • TECH       - Volatile growth stock (20% annual volatility)
    • DIVIDEND   - Stable dividend stock (12% annual volatility)
    • BOND       - Conservative bond (5% annual volatility)
    • CRYPTO     - Cryptocurrency (35% annual volatility)
    • COMMODITY  - Commodity index (18% annual volatility)

  Built-in Strategies:
    • buy_and_hold() - Hold single asset
    • balanced_portfolio() - Static multi-asset allocation
    • momentum_strategy() - Moving average crossover
    • rebalance_strategy() - Periodic rebalancing
    • Plus support for custom strategies!

  Metrics:
    • Total Return - Overall profit percentage
    • Annual Return - Annualized return rate
    • Max Drawdown - Worst peak-to-trough decline
    • Sharpe Ratio - Risk-adjusted return
