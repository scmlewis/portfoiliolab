    How to use PortfolioLab

    What is PortfolioLab?

    A free portfolio backtesting tool using real market data from Yahoo Finance. Test investment strategies historically to see how they would have performed.

    Quick Start

    1. Portfolio Setup — Enter stock/ETF symbols, set your date range and starting capital. Data loads automatically.
    2. Pick a Strategy — Use a Quick Start preset or select a strategy from the dropdown.
    3. Run Backtest — Click "Run Backtest" to see historical performance.

    Strategies

    Buy & Hold — Buy a single asset and hold for the entire period.
    Balanced Portfolio — Allocate across multiple assets with custom weights.
    Momentum — Uses moving average crossovers for trend-following.
    Rebalancing — Periodically rebalances back to target allocation.
    RSI Oversold — Buys when RSI drops below oversold level.
    MACD Crossover — Trades on MACD signal line crossovers.
    Bollinger Bands — Buys at lower band, sells at upper band.

    Advanced Features

    Quick Compare — Runs 4 strategies at once with side-by-side results.
    Portfolio Optimization — Finds optimal allocation using Modern Portfolio Theory.
    Efficient Frontier — Plots risk/return tradeoff with optimal portfolios.
    Save / Load Config — Save your setup and reload it later.

    Tips

    Data is cached for 10 minutes — re-loading is instant.
    Toggle dark mode with the moon/sun icon in the top bar.
    Your last backtest is saved and restored on reload.

    Built with Flask, Chart.js, and Yahoo Finance data.
